# Безумный транспорт: «Летающий самовар»

Автор ТЗ и тестов — Хвальчев Сергей Павлович, БСБО-16-23, №25. Стихия — воздух.

Самовар с площадкой для пилота, складными крыльями и паровым пропеллером. Встречный ветер замедляет полёт и увеличивает расход пара. На земле можно заправиться и сложить крылья.

## Реализация

Класс `FlyingSamovar` и доменные исключения находятся в `flying_samovar.py`. Публичные атрибуты доступны только для чтения. Методы проверяют аргументы до изменения состояния; расчёт расхода и проверка препятствий ничего не меняют.

Вопросы по контракту записываются в [BUGREPORT.md](BUGREPORT.md). ТЗ и тесты версии 1.0 сохранены без изменений.

## Запуск

Нужен Python 3.10+, установка зависимостей не требуется:

```bash
python3 -m unittest discover -s tests -t . -v
```

Реализация не требует сторонних библиотек. В проекте 30 тестов.

## Пример

```python
from flying_samovar import FlyingSamovar

samovar = FlyingSamovar("Пых", wing_span_m=2.5, max_speed_kmh=40)
samovar.deploy_wings()
print(samovar.move(10, "air"))  # 0.25 часа
samovar.land()
samovar.refuel(10)
print(samovar.get_status())
```
