## 1. Назначение

Летающий самовар перевозит одного пилота на небольшой площадке сбоку. Пар крутит пропеллер, а складные крылья держат аппарат в воздухе. Перед полётом крылья нужно раскрыть. При встречном ветре самовар летит медленнее и тратит больше пара.

## 2. Стихия и конструкционный элемент

Стихия — воздух. Обязательный элемент — крылья с размахом `wing_span_m`, которые создают подъёмную силу. Со сложенными крыльями лететь нельзя. По земле и воде самовар не передвигается.

## 3. Публичный интерфейс

### 3.1. Класс и модуль

Класс `FlyingSamovar` в файле `flying_samovar.py`. Исключения из раздела 6 находятся в том же модуле. Python 3.10+, сторонние библиотеки не нужны.

### 3.2. Конструктор

```python
def __init__(self, name: str, wing_span_m: float,
             max_speed_kmh: float, steam: float = 100.0) -> None:
```

| Параметр | Что означает | Допустимые значения |
| --- | --- | --- |
| name | Название | Строка, содержащая хотя бы один непробельный символ |
| wing_span_m | Размах крыльев, м | От 1 до 10 включительно |
| max_speed_kmh | Скорость в спокойном воздухе, км/ч | От 1 до 120 включительно |
| steam | Запас пара, условные единицы | От 0 до 100 включительно; по умолчанию 100 |

Название сохраняется как передано, без обрезки пробелов. Числа принимаются как `int` или `float`, но не `bool`. В атрибутах они хранятся как `float`. Неверный тип вызывает `TypeError`, значение вне диапазона, `nan` или бесконечность — `ValueError`. При нескольких неверных аргументах порядок проверки конструктора не задан.

### 3.3. Атрибуты

| Атрибут | Тип | Начальное значение |
| --- | --- | --- |
| name | str | Из конструктора |
| wing_span_m | float | Из конструктора |
| max_speed_kmh | float | Из конструктора |
| steam | float | Из конструктора |
| position_km | float | 0.0, общий пройденный путь |
| wings_deployed | bool | False |
| is_flying | bool | False |

Все атрибуты доступны только для чтения. Присваивание и удаление вызывают `AttributeError`, состояние не меняется. Изменить состояние можно только методами ниже.

Любой вызов, завершившийся исключением, оставляет все публичные атрибуты прежними. Проверки и расчёты тоже не меняют состояние. Если результат вычислений сравнивается в тесте, допустима погрешность до 7 знаков после запятой; неизменность состояния проверяется точным сравнением.

### 3.4. Методы

Все параметры можно передавать по имени или по позиции. Неуказанные атрибуты не меняются.

#### 3.4.1. Крылья

```python
def deploy_wings(self) -> None:
def fold_wings(self) -> None:
```

`deploy_wings` раскрывает крылья: `wings_deployed = True`. Можно вызвать на земле и в полёте. Повторный вызов ничего не меняет.

`fold_wings` складывает крылья: `wings_deployed = False`. На земле повторный вызов разрешён. В полёте вызывает `SamovarInFlight`. Оба метода не тратят пар и возвращают `None`.

#### 3.4.2. Движение

```python
def move(self, distance_km: float, terrain: str) -> float:
```

Дистанция — конечное число от 0 (не включительно) до 100 км (включительно). Правила числовых типов те же, что в конструкторе.

| terrain | Скорость | Расход пара |
| --- | --- | --- |
| air | max_speed_kmh | distance_km × 2 |
| headwind | max_speed_kmh / 2 | distance_km × 3 |
| ground, water | Движение запрещено | SamovarCannotMoveHere |

Неизвестная строка `terrain` вызывает `ValueError`, не строка — `TypeError`. Регистр важен, пробелы не обрезаются.

Перед полётом нужны раскрытые крылья, иначе `SamovarWingsFolded`. Если пара меньше расхода, возникает `SamovarNotEnoughSteam`. При точном равенстве полёт разрешён: остаток 0.0, `is_flying` остаётся `True` до посадки. Автоматической посадки нет.

При успехе увеличивается `position_km` на дистанцию, уменьшается `steam` на расход, `is_flying` становится `True`. Метод возвращает время в часах как `float`: дистанция / скорость. Повторный полёт добавляет путь к уже пройденному.

Порядок проверок: дистанция → terrain (тип и известное значение) → запрет ground/water → крылья → запас пара. Внутри проверки числа сначала проверяется тип, затем значение. Исключение относится к первой нарушенной проверке. Никаких дополнительных допусков при проверке запаса пара нет.

#### 3.4.3. Посадка

```python
def land(self) -> None:
```

Устанавливает `is_flying = False`. Пар и путь не меняет, крылья остаются раскрытыми. Можно приземлиться при нулевом запасе пара. Вызов на земле разрешён. Возвращает `None`.

#### 3.4.4. Расчёт расхода

```python
def calculate_energy(self, distance_km: float, terrain: str) -> float:
```

Возвращает расход пара как `float` по таблице в 3.4.2. Проверяет дистанцию и terrain в том же порядке, включая запрет ground/water. Расчёт возможен со сложенными крыльями, при нулевом запасе пара и в полёте. Ничего не меняет и не проверяет, хватит ли пара на поездку.

#### 3.4.5. Препятствия

```python
def can_overcome(self, obstacle: str) -> bool:
```

| obstacle | Результат |
| --- | --- |
| fence | True, если самовар в полёте и размах крыльев не меньше 2 м |
| river | True, если самовар в полёте |
| storm | Всегда False, в бурю лететь нельзя |

На земле результат для всех трёх препятствий — `False`. Метод только отвечает на вопрос, не перемещает аппарат и не тратит пар. Неизвестная строка вызывает `ValueError`, не строка — `TypeError`.

#### 3.4.6. Заправка

```python
def refuel(self, amount: float) -> None:
```

`amount` — конечное число больше 0 и не больше 1000. Дробные значения разрешены; `bool` и прочие нечисловые типы запрещены. Вначале проверяется тип (`TypeError`), затем значение (`ValueError`). В полёте заправка запрещена: после проверки аргумента возникает `SamovarInFlight`.

На земле запас увеличивается на `amount`, но не выше 100.0. При полном запасе корректный вызов разрешён. Возвращает `None`, остальные атрибуты прежние.

#### 3.4.7. Состояние

```python
def get_status(self) -> dict:
```

Возвращает новый словарь со всеми семью атрибутами из 3.3, без дополнительных ключей. Типы значений совпадают с таблицей. Изменение полученного словаря не влияет на самовар и на другие снимки.

## 4. Сценарии и тест-план

### 4.1. Модульные примеры

Для примеров: размах 2.5 м, скорость 40 км/ч.

1. Раскрыть крылья и вызвать `move(10, "air")` при запасе 100: время 0.25 ч, запас 80, путь 10, аппарат в воздухе (TC_M_11).
2. При запасе 5 попытаться пролететь 3 км: `SamovarNotEnoughSteam`, состояние прежнее (TC_M_14).
3. В полёте проверить забор: `True` при размахе от 2 м, при 1.5 м — `False` (TC_M_21).
4. На земле при запасе 60 долить 0.25: запас 60.25, возврат `None` (TC_M_22).

### 4.2. Сценарии через пилота

Во всех сценариях скорость 40 км/ч, размах 2.5 м, если не указано другое. Пилот вызывает публичные методы, не записывает значения в атрибуты.

#### TC_S_01. Поездка за чаем

**Given:** самовар на земле, запас 100.
**When:** пилот раскрывает крылья, летит 10 км и ещё 5 км в спокойном воздухе.
**Then:** время участков 0.25 и 0.125 ч, запас 70, путь 15, аппарат в полёте.
**When:** пилот садится и складывает крылья.
**Then:** аппарат на земле, крылья сложены, запас и путь прежние.

#### TC_S_02. Обратный путь против ветра

**Given:** запас 90.
**When:** пилот раскрывает крылья, летит 10 км в спокойном воздухе, затем 10 км против ветра.
**Then:** время 0.25 и 0.5 ч, запас 40, путь 20. Реку можно перелететь; проверка ничего не меняет.
**When:** пилот садится и складывает крылья.
**Then:** путь 20, запас 40, аппарат на земле.

#### TC_S_03. Не хватило пара

**Given:** запас 5, крылья раскрыты.
**When:** пилот пытается лететь 3 км в спокойном воздухе.
**Then:** SamovarNotEnoughSteam, состояние прежнее.
**When:** пилот доливает 1, летит 3 км, садится, доливает 10 и летит ещё 1 км.
**Then:** первый полёт оставляет 0 пара, последний — 8; итоговый путь 4, аппарат в полёте.

#### TC_S_04. Заправка после посадки

**Given:** запас 30.
**When:** пилот раскрывает крылья и летит 5 км в спокойном воздухе, затем пробует сложить крылья и заправиться.
**Then:** оба действия вызывают SamovarInFlight, запас 20 и путь 5 не меняются.
**When:** пилот садится, доливает 0.25, складывает и раскрывает крылья, летит 0.125 км против ветра.
**Then:** время 0.00625 ч, запас 19.875, путь 5.125, аппарат в полёте.

#### TC_S_05. Забор и река

**Given:** размах 2 м, запас 20, самовар на земле.
**When:** пилот проверяет все препятствия, раскрывает крылья и летит 1 км.
**Then:** на земле все результаты False; в полёте забор и река — True, буря — False. После проверок запас 18, путь 1.
**When:** пилот садится и снова проверяет препятствия.
**Then:** все результаты False.

#### TC_S_06. Посадка с пустым баком

**Given:** запас 20.
**When:** пилот раскрывает крылья и летит 10 км в спокойном воздухе.
**Then:** запас 0, путь 10, аппарат остаётся в воздухе.
**When:** пилот пытается лететь ещё 0.5 км.
**Then:** SamovarNotEnoughSteam, состояние прежнее.
**When:** пилот садится, складывает крылья, доливает 20, раскрывает крылья и летит 5 км против ветра, затем садится.
**Then:** запас 5, путь 15, крылья раскрыты, аппарат на земле.

## 6. Исключения

```text
Exception
└── SamovarError
    ├── SamovarWingsFolded
    ├── SamovarNotEnoughSteam
    ├── SamovarCannotMoveHere
    └── SamovarInFlight
```

Доменные классы — прямые наследники `SamovarError`, он — прямой наследник `Exception`.

| Исключение | Когда |
| --- | --- |
| TypeError | Неверный тип параметра, в том числе bool вместо числа |
| ValueError | Недопустимое значение, неизвестная строка, nan или бесконечность |
| AttributeError | Присваивание или удаление публичного атрибута |
| SamovarWingsFolded | Полёт со сложенными крыльями |
| SamovarNotEnoughSteam | Не хватает пара на весь участок |
| SamovarCannotMoveHere | Движение или расчёт для ground/water |
| SamovarInFlight | Складывание крыльев или заправка в воздухе |

Текст сообщений не проверяется, важен тип исключения и неизменность состояния.
